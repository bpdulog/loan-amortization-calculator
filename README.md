# Amortize — Monthly Loan Calculator

A standalone, no-build web project for exploring monthly loan amortization plans. Open `index.html` in a browser.

Features include loan-type presets, live sliders and number inputs, optional extra monthly payments with a custom starting month, saved preferences, an interactive balance trajectory (comparing standard payoff, accelerated paydown, and investing the difference), investment tradeoff analysis, a year-filtered payment schedule, and CSV export.
